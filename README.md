# ◉ QR Studio

**Премиум-генератор QR-кодов с дизайном**

## ✨ Возможности

### 📦 5 типов QR-кодов
- 🌐 **URL** — ссылки на сайты (автодобавление `https://`)
- 📝 **Текст** — произвольный текст
- 📶 **Wi-Fi** — мгновенное подключение к сети
- ✉ **Email** — письмо с готовой темой
- 📞 **Телефон** — звонок в один тап

### 🎨 Полный контроль над дизайном
- **7 готовых пресетов**: Classic, Neon, Ocean, Sunset, Mint, Elegant, Cyberpunk
- **5 стилей модулей**: квадраты, скруглённые, круги, точки, ромбы
- **3 стиля «глаз»** (уголков): квадратные, скруглённые, круглые
- **Градиентная заливка** — от цвета модулей к произвольному второму цвету
- **Выбор цветов** — передний план, фон, градиент через встроенный color picker
- **Вставка логотипа** в центр QR-кода (с подложкой, безопасно для сканирования)

### ⚙️ Профессиональные настройки
- **Уровни коррекции ошибок** L/M/Q/H (7% – 30%)
- **Настраиваемый размер** модулей (5–20)
- **Экспорт в PNG и JPG** в оригинальном разрешении
- **История** последних 15 кодов с быстрой загрузкой
- **Живое превью** — изменения видны мгновенно

### 💎 Качество
- **3× суперсэмплинг** — гладкие края без «лесенки»
- **Скан-совместимость** — все стили корректно читаются iPhone/Android
- **Тёмная тема** интерфейса (Catppuccin Mocha)
- **Кроссплатформенность** — Windows, macOS, Linux

## 🚀 Установка

### 1. Клонируй репозиторий
```bash
git clone https://github.com/username/qr-studio.git
cd qr-studio
```

### 2. Установи зависимости
```bash
pip install -r requirements.txt
```

> ⚠️ Требуется **Pillow 8.2+** (для `rounded_rectangle`). Если установлена старая версия:
> ```bash
> pip install --upgrade pillow
> ```

### 3. Запусти
```bash
python qr_studio.py
```

## 📖 Использование

1. **Выбери тип данных** на вкладке сверху (URL / Текст / Wi-Fi / Email / Телефон)
2. **Введи данные** в поле
3. **Настрой дизайн** — пресет, стиль модулей, цвета, градиент
4. **Добавь логотип** (опционально) — кнопка «Выбрать»
5. **Нажми «⚡ Сгенерировать QR»** — или просто `Enter` в поле ввода
6. **Скачай** в PNG или JPG кнопкой под превью

Все настройки применяются **мгновенно** — отдельная кнопка «Применить» не нужна.

---

## 🧠 Как это работает

Проект **не использует стандартный** `qr.make_image()` — вместо этого:

1. **Извлекается матрица** через `qr.get_matrix()`
2. **Каждый модуль** рисуется отдельно (квадрат / круг / ромб / скруглённый) через PIL
3. **Finder patterns** (3 блока 7×7 в углах) распознаются и рисуются отдельным стилем
4. **Суперсэмплинг 3×** — рендер в 3 раза больше, затем уменьшение LANCZOS'ом для гладких краёв
5. **Градиент** рассчитывается интерполяцией по диагонали `(row + col) / (2n - 2)`

Это даёт **полный контроль** над внешним видом и позволяет создавать по-настоящему кастомные QR-коды.

## 🤝 Вклад

PR'ы приветствуются! Если есть идеи:

- 🐛 **Баг** — открывай [issue](https://github.com/username/qr-studio/issues) с описанием и скриншотом
- 💡 **Идея** — сначала обсуди в issue, потом делай PR
- 🎨 **Новый пресет** — добавь в `PRESETS` (словарь в начале `qr_studio.py`) и пришли скриншот

### Как добавить свой пресет

```python
PRESETS = {
    # ...
    "MyStyle": {
        "fg": "#ff0000",
        "bg": "#000000",
        "grad": "#00ff00",
        "module": "rounded",  # square | rounded | circle | dots | diamond
        "eye": "circle",      # square | rounded | circle
    },
}
```
